# Fonts and licensing

The implementation is specified for:
- Inter — Latin/UI
- Noto Sans Arabic — Arabic/UI

Both families are commonly distributed under the SIL Open Font License (OFL), but this handoff intentionally does **not** redistribute WOFF2 binaries.

Use your organization's approved font source, store the chosen WOFF2 files under:
`themes/custom/digital_platform/assets/fonts/`

Expected file names:
- Inter-Regular.woff2
- Inter-Medium.woff2
- Inter-SemiBold.woff2
- Inter-Bold.woff2
- NotoSansArabic-Regular.woff2
- NotoSansArabic-Medium.woff2
- NotoSansArabic-SemiBold.woff2
- NotoSansArabic-Bold.woff2

Before production, retain the corresponding OFL license text next to the font binaries and verify the exact files' provenance.
